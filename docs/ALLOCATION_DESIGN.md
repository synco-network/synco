# SYNCO Allocation Design

## Maximum Supply
10,000,000 SYNCO

## Initial Allocation
- Staking/Validator: 1,000,000 SYNCO (10%)
- Users/Ecosystem: 8,500,000 SYNCO (85%)
- Developer: 500,000 SYNCO (5%)

## Monetary Policy
- No additional minting.
- No inflation.
- Total supply must never exceed 10,000,000 SYNCO.
- Allocation transfers must not create new supply.
- Each allocation can only be distributed once.

## Important
This allocation contract distributes an existing SYNCO balance.
It does not create the native SYNCO gas coin.
Native supply enforcement must be implemented at the blockchain protocol level.
